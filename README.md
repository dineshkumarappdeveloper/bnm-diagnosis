# BNMDiagnosis

Offline-first laboratory management (LIMS) for diagnostic labs — desktop
first (Windows/macOS/Linux), Android secondary. Patients, test catalog with
reference ranges, sample accessioning, results entry, pathologist approval,
printable reports, GST billing, and optional sync into the BNM ecosystem
(EMR lab orders in, results back). Sold standalone (license key) or as part
of BNM. Built with Kotlin Multiplatform + Compose.
